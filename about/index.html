spin roughについて

spinは「紡ぐ」。
roughには、laugh(笑顔)への想いを込めています。

人と人の関係を、笑顔で紡ぐ。それが、この会社の根っこです。

MISSION / VISION

大切にしていること

MISSION

日本の歴史と心を、22世紀へ紡ぐ。

VISION

誰もが、何かを紡ぐ一人になる。

会社の姿

働く人が一番誇らしく、お客様が一番感動している会社であり続ける。

VALUES

私たちの行動

  1. 自ら挑む側に立つ

    受け取る側に回らない。お客様に価値を届けるために、自分の手で最後までやり切る。

  2. 礼を尽くす

    出会うすべての縁に。先人には、歴史を受け継ぎ、より良い形にすることで。お客様には、一人ひとりに真心で向き合うことで。仲間には、挨拶と感謝を言葉にすることで。

  3. 卓越し、圧倒する

    もてなしと技に、どの企業よりもこだわり抜く。AIは楽をするためではなく、本質の価値を磨くために使う。

  4. 一歩に、想いを込める

    目標までの一歩一歩に、想いを込める。遅さを恐れず、薄さを恐れる。その積み重ねが、歴史になる。

  5. 22世紀から考える

    目先の得より、百年続く信頼を選ぶ。

MESSAGE

代表挨拶

日本には、何十年、何百年と続いてきた技ともてなしがあります。私たちは、それを22世紀まで続く形で、次の時代に渡したいと考えています。

技ともてなしを続けている会社ほど、その後ろで、社長や社員の方が書類と事務に追われています。AIは、楽をするためではなく、本質の価値を磨くために使うものだと私たちは考えています。だから、裏方の仕事をAIと一緒に引き受けて、技ともてなしに時間を使える会社を増やしていきます。

小さな会社です。だからこそ、一社一社に礼を尽くし、現場に伺い、同じものを見ながら一緒に考えます。まずは、いちばん面倒な仕事を一つ、教えてください。
